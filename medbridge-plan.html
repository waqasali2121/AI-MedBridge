rocket_launchBuild Phases

Phase 1

Foundation

Days 1–3
  • FastAPI + PostgreSQL + SQLAlchemy setup
  • All 6 database models + Alembic migrations
  • JWT authentication (register, login, roles)
  • Expo project + NativeWind + tab nav
  • Next.js dashboard + sidebar/header layout
  • Docker Compose (DB + Ollama)
Phase 2

Upload & Extraction

Days 4–7
  • File upload endpoint (PDF/JPG/PNG, 10MB max)
  • PyMuPDF text extraction (primary path)
  • Tesseract OCR fallback for scanned docs
  • LLM structured extraction via Ollama
  • Mobile upload flow + progress indicator
  • Extraction review screen with editable cards
Phase 3

Confirmation & Rules

Days 8–10
  • Rule engine: duplicates, missing fields, confidence
  • User confirmation flow with warning acknowledgment
  • Language selection (English / اردو)
  • Audit logging for all state changes
Phase 4

AI Explanation

Days 11–14
  • Constrained English generation prompt
  • Urdu translation/generation prompt
  • Output safety validation (no diagnosis/dose)
  • Handover card data builder
  • Mobile AI handover screen + language toggle
Phase 5

Pharmacist Review

Days 15–18
  • Dashboard: KPI cards + review queue (from designs)
  • Split-pane review screen (from designs)
  • Approve / Reject / Comment workflow
  • Bilingual AI explanation panel (EN/UR tabs)
  • Sticky action bar with legal responsibility notice
Phase 6

Handover Cards

Days 19–21
  • Color-coded medication cards (from designs)
  • Bilingual instruction blocks (EN + Urdu RTL)
  • Daily schedule visualizer (AM/PM/Night)
  • Export: Print / PDF / Send to App / Share
  • Prescription history list
Phase 7

Safety Testing

Days 22–25
  • End-to-end workflow testing
  • 10 synthetic test scenarios from PRD
  • AI safety validation (7 safety requirements)
  • Demo data + demo script preparation
Phase 8

Polish & Deploy

Days 26–28
  • Error handling (6 error cases from PRD)
  • Urdu RTL support polish
  • Docker deployment + seeding script
  • 90-second hackathon demo preparation
